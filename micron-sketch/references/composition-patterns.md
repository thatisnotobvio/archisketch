# Composition Patterns

## Description
Pick the pattern that matches what the source photo actually shows — don't default to the same framing regardless of input.

## Pattern: Corner three-quarter (default for most street-level photos)
- Building corner facing camera, two facades visible at an angle.
- Roughly eye-level or a slight worm-eye angle (looking a little upward), not a drone/top-down view.
- Full building shown top to bottom with margin/negative space around it — not a tight crop.
- Use this when the source photo shows a corner or angled view of the building, which is most real-estate and street photography.

## Pattern: Straight elevation
- Single facade shown flat-on, minimal perspective distortion.
- Use only when the source photo is itself a flat, straight-on shot — don't invent a flat elevation from an angled photo.

## Pattern: Close detail crop
- A specific architectural feature (entryway, a window bay, a material junction) framed tightly, cropping out the rest of the building.
- Use when the user explicitly asks for a closer/detail view, or when the source photo itself is already a detail shot rather than a full elevation.

## Choosing light direction and shadow
- Match the shadow direction visible in the source photo where discernible.
- If the photo gives no clear cue, choose a direction that puts one full facade in hatched shadow and one in flat light — the style depends on that contrast to read well.

## Anti-reptition rule
- Two different source buildings should never produce visually identical compositions just because they're both "houses." Vary framing, crop, and which facade is in shadow based on what's actually different about each building — don't fall back on a single memorized layout.
- If revising a prompt for the same building (different color accent, closer crop, etc.), keep the composition consistent with the original unless the user specifically asks to change the framing.
